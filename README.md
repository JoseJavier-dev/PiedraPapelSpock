#  Piedra, Papel, Tijeras, Lagarto, Spock

# Enlace a la página web

https://josejavier-dev.github.io/PiedraPapelSpock/

Este proyecto es una tarea de 1ºDam que consiste en una implementación interactiva del clásico juego ampliado **Piedra, Papel, Tijeras, Lagarto, Spock**, con interfaz gráfica, IA con distintos niveles de dificultad y modo multijugador local.

---

##  Funcionalidades principales

###  IA con niveles de dificultad

El juego incluye una inteligencia artificial configurable:

- **Fácil**: la IA pierde intencionalmente en la mayoría de casos.
- **Medio**: comportamiento aleatorio con ligeros ajustes estratégicos.
- **Aleatorio**: decisiones completamente aleatorias.
- **Difícil**: la IA predice y contrarrestra al jugador el 99% de las veces.

---

###  Modo 2 jugadores (local)

Permite jugar entre dos personas en el mismo dispositivo:

- Cada jugador introduce su nombre.
- Sistema de puntuación independiente.
- Botones para sumar puntos manualmente.
- Control de victoria compartido.

---

###  Personalización visual

El usuario puede modificar la apariencia del juego en tiempo real:

- Cambio del color del texto.
- Cambio del color de fondo.

---

###  Sistema de sonidos

El juego incluye efectos de sonido:

- Sonido específico para cada elección (piedra, papel, tijeras, lagarto, Spock).
- Control de volumen mediante slider.
- Activación/desactivación de sonidos.
- Música de fondo en bucle.

---

###  Sistema de puntuación y victoria

- Marcador para jugador e IA.
- Configuración del número de victorias necesarias para ganar.
- Reinicio automático al finalizar la partida.
- Mensajes personalizados según el resultado.

---

###  Interfaz dinámica y responsive

- Interfaz dividida en zona de juego y panel de configuración.
- Actualización en tiempo real de nombres y puntuaciones.
- Modal informativo con las reglas del juego.
- Botones interactivos con efectos visuales.

---

###  Lógica del juego

- Uso de objetos literales para definir reglas y acciones.
- Sistema optimizado para determinar ganadores sin estructuras condicionales complejas.
- Mensajes dinámicos que describen la interacción entre jugadas.
